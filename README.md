# Система для аналізу переглядів захистів дисертацій на YouTube

---

## 1. Загальний опис проєкту

Програмна система призначена для збору, структурування, статистичного аналізу та візуалізації даних про публічні трансляції захистів дисертаційних робіт (PhD та докторських), розміщених на YouTube-каналах українських закладів вищої освіти та наукових установ.

### Основні функціональні можливості:
* **Збір даних:** Інтеграція з YouTube Data API v3 з пакетним опитуванням (до 50 ідентифікаторів на запит) та обробкою обмежень квот.
* **Обробка трансляцій:** Автоматичне розпізнавання багаточастинних захистів («частина 1», «частина 2») та групування їх у єдину дисертаційну роботу на основі зіставлення метаданих (ПІБ здобувача, тема, канал, дата).
* **Статистичний аналіз:** Розрахунок середніх та медіанних показників, лінійних кореляцій Пірсона (залежність переглядів від тривалості, субтитрів, віку публікації), аналіз часової динаміки переглядів.
* **Порівняльний аналіз ЗВО:** Дослідження структури та шаблонів оформлення метаданих спеціалізованими вченими радами університетів України.
* **Аналітична звітність:** Інтерактивний веб-дашборд та експорт даних у форматах PDF і Microsoft Excel (XLSX) з вибором рівня деталізації по частинах відео.

---

## 2. Технологічний стек

* **Мова програмування:** Java 21 (LTS)
* **Фреймворк:** Spring Boot 3.4 (Spring MVC, Spring Data JPA)
* **База даних:** H2 Database (файловий режим зі збереженням на диску) / PostgreSQL
* **Користувацький інтерфейс:** Thymeleaf, Bootstrap 5, Chart.js
* **Генерація звітів:** Apache POI (Excel), OpenPDF (PDF)
* **Тестування:** JUnit 5, Mockito, AssertJ, Spring Boot Test

---

## 3. Архітектура та принципи проєктування

* **Шари застосунку:** Дотримання класичної трирівневої архітектури Spring Boot (`Controller` $\rightarrow$ `Service` $\rightarrow$ `Repository`).
* **Модульність:** Розділення логіки на незалежні компоненти збору даних, статистичного аналізу, фільтрації та експорту звітності.
* **Надійність даних:** Використання механізму транзакцій (`@Transactional`) для запобігання порушенню цілісності бази даних при збоях мережевих викликів.
* **Логування:** Фіксація ключових подій та виняткових ситуацій за допомогою фасаду SLF4J.

---

## 4. Інструкція зі встановлення та запуску

### 4.1. Системні вимоги
* Комплект розробки Java (JDK) версії 21 або новішої.
* Інструмент автоматизації збірки Apache Maven 3.9+.
* Сучасний веб-браузер.

### 4.2. Налаштування середовища
Створіть файл конфігурації `.env` на основі наданого зразка:
```bash
cp .env.example .env
```

Вкажіть ключ YouTube Data API у файлі `.env`:
```properties
YOUTUBE_API_KEY=AIzaSyYourActualSecretApiKeyHere
SERVER_PORT=8080
```
*Примітка:* Якщо API-ключ не вказано або ліміт запитів вичерпано, застосунок використовує вбудовану тестову вибірку даних.

### 4.3. Збірка та запуск застосунку
```bash
# Збірка проєкту та запуск тестів
mvn clean package

# Запуск програми
mvn spring-boot:run
```

Після запуску інтерфейс доступний за адресами:
* Головна сторінка: `http://localhost:8080`
* Консоль бази даних H2: `http://localhost:8080/h2-console`  
  (Рядок підключення: `jdbc:h2:file:./data/dissertations`)

---

## 5. Тестування системи

У проєкті реалізовано автоматизоване тестування на різних рівнях:
* **Модульні тести (Unit Tests):** верифікація статистичних розрахунків, регулярних виразів парсингу та алгоритмів групування частин відео.
* **Інтеграційні тести (Integration Tests):** перевірка роботи бази даних, збереження знімків статистики та обробки HTTP-запитів контролерами.
* **Навантажувальні тести (Performance Tests):** перевірка продуктивності операцій фільтрації та сортування на тестовій вибірці з 5 000 записів.

Запуск тестового набору:
```bash
mvn test
```
